# 全球订单交付指挥中心 · 双页联动模板

> 可直接复用/二开的企业级订单交付可视化模板。两个独立页面，顶部导航互通，零构建依赖。

## 页面

| 文件 | 说明 |
|------|------|
| `index.html` | **指挥中心首页** — 全球订单交付大屏，地图 + KPI + 物流链路 + 生产任务 |
| `data.html` | **数据填报页** — 可编辑三栏工作台，周维度进度管理，草稿自动存 localStorage |

## 技术要点

- 纯静态 HTML，双击即可打开，无 Node / npm 依赖
- 大屏：ECharts 内嵌（Apache License 2.0）
- 填报页：localStorage 自动存草稿，支持 JSON 导出
- 数据周：ISO 周自动切换，编辑只写当前周，历史周只读留痕

## 使用

```bash
git clone <repo-url>
# 直接双击 index.html 打开
# 或用任何静态服务器：
python -m http.server 8000
```

## 后续扩展

- 业务数据通过导出 JSON 对接后端 API
- 新增页面：放进目录，在两页顶栏加 `<a href="xxx.html">` 即可
- 多品牌复用：复制整个目录改名即可，无品牌标识残留
